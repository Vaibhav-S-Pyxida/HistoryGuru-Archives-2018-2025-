# HistoryGuru Archives

An interactive, single-page web application designed for archiving, searching, and contextualizing multi-year historical chat logs. Built with React and styled using Tailwind CSS, HistoryGuru Archives provides a seamless interface to navigate large WhatsApp export logs spanning multiple years (2017–2026), featuring global full-text search, dark/light themes, and optional AI-assisted contextual analyses.

# Features

1) Multi-Year Timeline Indexing: Automatically parses WhatsApp .txt exports and categorizes chat messages by calendar year.

2) Global Chronological Search: Perform instant full-text searches across years and author names to highlight specific discussions instantly.

3) Adaptive Discord-Inspired UI: Clean, responsive layout with support for system-wide Dark and Light mode toggles.

4) AI-Powered Contextual Assistant: Optional inline contextual analysis, yearly summary digests, and an interactive historical query bot.

5) Privacy & Client-Side Processing: All chat parsing occurs locally within your web browser—no user log data is transmitted or stored on remote servers.

6) Zero-Build GitHub Pages Deployment: Fully self-contained in a single index.html file—no Node.js, Vite, or complex build steps required.
